# Ravi Digital Portfolio

## Upload to GitHub Pages
1. Upload all files/folders in this project to your GitHub repository.
2. Keep `images/character.png` in the `images` folder.
3. Enable GitHub Pages from Settings → Pages.
4. Your custom domain can be connected through DNS without transferring the domain.

## Add templates
Edit `templates.js` and replace each `link` with your real Gumroad/Lemon Squeezy/WhatsApp checkout link.

## Add daily blog posts
1. Create a new HTML article inside `blog/`.
2. Add its title, excerpt, date, tag and URL to `blog/posts.js`.
3. Commit/push to GitHub. The homepage and full blog will show the new post.

## Important
Replace the placeholder GitHub/LinkedIn links and the WhatsApp number (`91XXXXXXXXXX`) before publishing.
