How to Connect a Custom Domain to GitHub Pages

Published on Ravi Digital • Practical guide

You do not need to transfer a domain to use it with GitHub Pages. You can keep the domain at your registrar and point its DNS records to GitHub Pages.

Basic setup

Enable GitHub Pages in your repository, add your custom domain in the Pages settings, then configure the domain's DNS records at your registrar.

Root domain

For a root domain, GitHub Pages uses its published A-record addresses. For a subdomain such as www, use a CNAME pointing to your GitHub Pages hostname.

HTTPS

After DNS propagation and verification, enable HTTPS in the GitHub Pages settings.

DNS propagation can take time, so a newly changed domain may not work everywhere immediately.
