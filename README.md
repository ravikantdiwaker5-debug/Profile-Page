# Ravi Digital — GitHub-ready portfolio

This version uses only HTML, CSS and JavaScript, so it can be uploaded directly to GitHub Pages.

## Files to upload

- `index.html`
- `style.css`
- `script.js`
- `favicon.svg`
- the complete `images` folder

Keep every file and folder name unchanged.

## Add a daily blog post

1. Put the new photo inside the `images` folder.
2. Open `script.js`.
3. At the top, copy one post object inside `blogPosts` and paste it above the others.
4. Change its `id`, `category`, `date`, `title`, `image`, `imageAlt`, `excerpt` and `content`.
5. Save the file and upload the changed `script.js` plus the new photo to GitHub.

The latest object in the list appears first on the website. Clicking **Read blog** opens the complete post.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload all files from this folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

GitHub will show your public website link after deployment finishes.
